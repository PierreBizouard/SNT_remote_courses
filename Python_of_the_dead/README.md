# Python of the Dead

Entraînement hors cours (chapitre Python) : des zombies arrivent avec un ordre en français, l'élève tape la ligne Python correspondante pour les abattre.

- La classe `Gun` (attributs `munitions`, `couleur`, `enraye` ; méthodes `afficher()`, `viser()`, `tirer()`, `reload()`, `debloquer()`) est présentée au départ.
- Commandes simples et répétées ; un panneau « mémoire de Python » montre les variables, les objets et les listes à chaque ligne.
- Les armes s'enrayent (`gun.debloquer()`) et se vident (`gun.reload()`) ; dans le sac (liste), sortir la grenade souffle les zombies, le bandage rend une vie.
- Vagues : 1 méthodes, 2 attributs, 3 listes (`append`, `pop`, `remove`, `sac[0]`, `len`), 4 la horde (deux objets du même plan, boss).
- Mini-interpréteur intégré avec messages d'erreur à la Python (NameError, AttributeError, TypeError…) et une explication en français.
- Pas de note ; progression enregistrée dans le navigateur. Taper `prof` dans la console au menu débloque toutes les vagues.
